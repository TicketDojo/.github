# 대규모 티켓팅 시뮬레이션 플랫폼

## 프로젝트 소개
이 프로젝트는 대규모 트래픽 환경에서 발생하는 티켓팅(예매) 동시성 문제를 실험적으로 해결해보기 위한 시뮬레이션 프로젝트입니다. <br>
단순한 기능 구현 수준을 넘어, 실제 서비스 아키텍처가 확장되는 과정을 직접 경험하고 성능 향상을 단계적으로 관찰하는 데 목표를 두고 있습니다.

## 프로젝트 목표
### 대규모 트래픽에서의 동시성 제어 학습
티켓팅 시스템은 짧은 시간에 폭증하는 요청을 안정적으로 처리해야 하며, 특히 <b>대기열 관리, 좌석 점유 처리, 순위 계산, 만료 처리</b> 등 복잡한 동시성 문제가 발생합니다. <br>
이 프로젝트는 이러한 문제를 <b>가장 기본적인 환경(SpringBoot + MySQL)</b> 시작하여 점진적으로 확장하며 시스템이 어떻게 변하는지 직접 관찰합니다.

## 기술 확장 로드맵
처음부터 고급 기술(Redis, Kafka, MSA)을 사용하는 방식이 아니라, 기술적 단계를 나누어 한계 -> 개선 -> 성능 향상 과정을 직접 확인하는 방식으로 진행합니다.

## 주요 기능
### 1) Spring Security + JWT 인증/인가
### 2) 대기열 시스템
- Waiting -> Active -> Expired 상태 기반 흐름 관리
- 고유 토큰 기반 순번 조회
### 3) 좌석 점유/홀딩
- 20초 TTL 기반 좌석 잠김
- 타임아웃 시 자동 해제
- 결제 창 진입 시 20초 TTL 재부여
### 4) 실시간 상태 동기화
- WebSocket 기반 좌석 상태 전파
